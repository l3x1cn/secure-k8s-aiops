# T14 · Sekrety generowane przy wdrożeniu i gitleaks pre-commit (issue #14)

## Context

Issue #14 (T14, R2 Bezpieczeństwo, Sprint 2). Zależy od T04, które jest już scalone. Cel: żaden sekret nie trafia do repozytorium. Zakres z issue:
- `make secrets` (`scripts/secrets.sh`): sekrety z sekcji „Sekrety” z `openssl rand -hex 32`, tylko brakujące (stabilne między `make up`), bez zapisu na dysk i bez wypisywania;
- `make grafana-password` wypisuje hasło Grafany na żądanie;
- `.pre-commit-config.yaml` z hookiem gitleaks (przypięta wersja) i instrukcja `uvx pre-commit install` w README;
- `tests/security/test_secrets.py`: w `deploy/` nie ma `kind: Secret` z `data`/`stringData`; gitleaks na całej historii nie ma znalezisk.

Kryteria akceptacji:
1. Testy przechodzą. Świeży klon + `make up` działa bez żadnych plików z sekretami.
2. Commit z fałszywym kluczem jest blokowany lokalnie przez pre-commit.

Komentarz w #14 (DreadGoblin, po PR #55, T16): `scripts/secrets.sh` tworzy już `monitoring/grafana-admin`. W T14 zostają `make grafana-password`, pre-commit i test. Tymczasowe polecenie `kubectl … | base64 -d` w README ma zastąpić `make grafana-password`.

Decyzja właściciela (2026-11-11): hook pre-commit bierze gitleaksa z `mise.toml` (`repo: local`, `mise exec -- gitleaks …`), a nie z hooka repozytorium gitleaks/gitleaks z `rev`. PR opisuje to jako odstępstwo od dosłownego tekstu issue.

Stan docelowy:
- nowy cel `make grafana-password`;
- `.pre-commit-config.yaml` z lokalnym hookiem gitleaks;
- `tests/security/test_secrets.py` z 3 testami, które działają bez klastra; `pyyaml` w grupie `dev`;
- kontrakt w `docs/architektura.md`, README i macierz w `docs/bezpieczenstwo.md` ze stanem „działa”;
- `scripts/secrets.sh` bez zmian.

## Warunek wstępny (główny agent, przed startem delivery)

W korzeniu repozytorium:

```bash
git status --short       # oczekiwane: tylko ?? docs/plans/2026-11-11-t14-sekrety-gitleaks.md
rm docs/plans/2026-11-11-t14-sekrety-gitleaks.md   # stary szkic; zastępuje go ten plan
git switch main && git pull --ff-only
git switch -c t14-sekrety
git status --short       # pusto
```

Jeśli szkicu już nie ma, pomiń `rm`. Hook pre-commit instaluje dopiero krok 3 Verification. Zainstalowany przed Task 2 przerywałby commity, bo nie byłoby jeszcze `.pre-commit-config.yaml`.

## Approach

Stosy: Task 1, 2 i 4 to „pozostałe” (Makefile, YAML, Markdown), Task 3 to Python. Taski są od siebie niezależne. Kolejność 1 → 2 → 3 → 4, bo Task 4 opisuje nazwy z Tasków 1–3. Taski nie potrzebują klastra; przebiegi na klastrze i próba pre-commit są w Verification.

Decyzje wspólne:
- Bez zmian: `scripts/secrets.sh`, `make secrets`, `make urls`, `mise.toml`, CI i Dependabot.
- Hook to `repo: local` z `mise exec -- gitleaks …`:
  - używa tej samej binarki co `make gitleaks` i job CI `secrets` (8.30.1 z `mise.toml`, sumy w `mise.lock`), więc wersja jest zapisana w jednym miejscu;
  - przy commicie nie potrzebuje Go ani sieci;
  - koszt: commit wymaga `mise` w PATH. Bez niego hook kończy się błędem i commit nie powstaje.
- Instalacja hooka: `uvx pre-commit@4.7.0 install`, czyli polecenie z issue z przypiętą wersją pre-commit.
- Test parsuje YAML przez PyYAML (`yaml.safe_load_all`) z grupy `dev`. Biblioteka standardowa nie ma parsera YAML, a kubectl bez serwera nie parsuje manifestów.

```python
# Sekrety poza repozytorium (T14): w deploy/ nie ma Secretu z data ani stringData,
# a gitleaks nie znajduje sekretów w historii HEAD. Sekrety tworzy przy wdrożeniu
# `make secrets` (scripts/secrets.sh; docs/architektura.md, sekcja „Sekrety”).
# Test nie potrzebuje klastra. Sprawdza każdy plik YAML w deploy/ (także taki,
# którego nie dołącza żaden kustomization) i wynik `kustomize build` każdego
# overlayu z deploy/overlays (Secret z secretGenerator). Historię skanuje
# `make gitleaks`, jak wymagany job CI `secrets`: tylko HEAD, bo inne gałęzie
# (np. origin/t06-test-sekret) celowo mają fałszywy klucz.
# Uruchomienie: uv run --locked pytest tests/security/test_secrets.py
# (kustomize z mise.toml w PATH; make sam dodaje narzędzia z mise do PATH).
import shutil
import subprocess
from pathlib import Path

import pytest
import yaml

pytestmark = pytest.mark.security

REPO_ROOT = Path(__file__).resolve().parents[2]
DEPLOY = REPO_ROOT / "deploy"


def secrets_with_values(document: object) -> list[str]:
    """Secrety z niepustym data albo stringData; w kind: List także elementy."""
    if not isinstance(document, dict):
        return []
    if document.get("kind") == "List":
        items = document.get("items") or []
        return [found for item in items for found in secrets_with_values(item)]
    if document.get("kind") != "Secret":
        return []
    if not (document.get("data") or document.get("stringData")):
        return []
    metadata = document.get("metadata") or {}
    return [f"Secret {metadata.get('namespace', '-')}/{metadata.get('name', '-')}"]


def test_deploy_files_have_no_secret_values():
    paths = sorted(
        path
        for path in DEPLOY.rglob("*")
        if path.is_file() and path.suffix in {".yaml", ".yml"}
    )
    assert paths, f"brak plików YAML w {DEPLOY}"
    found = []
    for path in paths:
        with path.open() as stream:
            for document in yaml.safe_load_all(stream):
                for secret in secrets_with_values(document):
                    found.append(f"{path.relative_to(REPO_ROOT)}: {secret}")
    assert not found, "\n".join(found)


def test_overlays_render_no_secret_values():
    if shutil.which("kustomize") is None:
        pytest.fail("Brak kustomize w PATH: aktywuj mise albo użyj `mise exec --`.")
    overlays = sorted(
        path.parent for path in DEPLOY.glob("overlays/*/kustomization.yaml")
    )
    assert overlays, "brak overlayów z kustomization.yaml w deploy/overlays"
    found = []
    for overlay in overlays:
        name = overlay.relative_to(REPO_ROOT)
        result = subprocess.run(
            ["kustomize", "build", str(overlay)],
            capture_output=True,
            text=True,
            timeout=60,
        )
        assert result.returncode == 0, f"kustomize build {name}: {result.stderr}"
        for document in yaml.safe_load_all(result.stdout):
            for secret in secrets_with_values(document):
                found.append(f"{name}: {secret}")
    assert not found, "\n".join(found)


def test_history_has_no_leaks():
    # make gitleaks ma --redact, więc komunikat błędu nie pokazuje wartości.
    result = subprocess.run(
        ["make", "gitleaks"],
        cwd=REPO_ROOT,
        capture_output=True,
        text=True,
        timeout=120,
    )
    assert result.returncode == 0, result.stdout + result.stderr
```
